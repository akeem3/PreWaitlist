### Tailwind v4 Gotcha

Unlayered CSS (plain CSS classes in `globals.css`) has **higher precedence** than Tailwind's layered utilities. When a plain CSS class sets a property (e.g., `.text-overline { text-transform: uppercase }`), Tailwind's `normal-case` utility cannot override it. Workaround: use inline styles or replace plain CSS classes with Tailwind utilities.
